# Контроль веса: веб-интерфейс + телеграм-бот

## Описание
Персональный сервис контроля веса — сайт с интерактивным графиком (FastAPI + Chart.js).
Данные хранятся в SQLite (`data/app.db`) и общие для сайта и бота: бот продолжает
рисовать графики из той же базы, если его запустить.

**Запуск телеграм-бота на данный момент закомментирован** (`bot.py` и сервис `bot`
в `docker-compose.yaml`) — работает только веб-сервис.

## Запуск сайта

Локально:
```bash
uvicorn web.main:app --host 0.0.0.0 --port 8080
```

Через docker (только веб-сервис):
```bash
docker-compose up --build
```

Требуется `.env` с переменными:
- `WEB_TOKEN` — токен доступа к сайту (вводится в окне входа, хранится в localStorage браузера)
- `tg_token`, `my_tg_id` — нужны только при возврате бота (и для локальных импортов `app.settings`)

Сайт:
- окно входа по токену
- график веса: по умолчанию 14 дней, переключатели месяц/квартал/год/всё, линия тренда
- клик по точке графика — правка или удаление записи
- кнопка «Ввести вес»: дата по умолчанию сегодня, вес по умолчанию — последний сохранённый, кнопки ±0.1 кг

При первом старте миграция из JSON (`data/*_weights.json`) происходит автоматически, файл остаётся как резервная копия.

## Команды бота (на паузе)

### Основные команды
- `/kettlebell` - Получить случайную тренировку по уровню сложности (morning, easy, medium, hard)
- `/weight` - Добавить запись о весе (inline клавиатура)
- `/weight_fill` - Проставить вес за дату
- `/weight_` - Вывести график веса за период
- `/weight_save` - Получить файл с данными о весе
- `/save_workout` - Получить файл с данными о тренировках
- `/street_wo` - Записать подтягивания и отжимания (inline клавиатура)

### Команды управления тренировками
- `/add_workout` - Добавить новую тренировку
- `/remove_workout` - Удалить тренировку
- `/list_workout` - Просмотреть все тренировки

## Как вернуть бота
1. Раскомментировать запуск в конце `bot.py` (`asyncio.run(main())`)
2. Раскомментировать сервис `bot` в `docker-compose.yaml` (или запустить `python -m bot` локально)
